# Fundación 25 de Mayo — A.FA.DI.MA.

Sitio web de la Fundación 25 de Mayo (Asociación de Familiares y Amigos de personas con Discapacidad de Malagueño, Córdoba).

Sitio estático: `index.html` (inicio), `sumate.html` (¿Cómo ayudar?), `styles.css`, `app.js` e `img/`.
No necesita compilación: se publica tal cual en Vercel, Netlify o GitHub Pages.

## Formularios
Los formularios de contacto y voluntariado envían a a.fa.di.ma@hotmail.com mediante FormSubmit.
El primer envío dispara un mail de activación a esa casilla que hay que confirmar una sola vez.
